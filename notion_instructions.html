Checks à faire sur les datasets utilisés

  • Vérification du nombre de lignes avec des données manquantes (si possible inférieur à 10%)

    df.isna().sum()
    df.isna().mean()

  • Vérification du nombre de données manquantes par feature (supprimer la feature si plus de 5% de valeurs manquantes)
  • Identifier les outliers s’il y en a - https://scikit-learn.org/stable/modules/outlier_detection.html

    df.describe()

  • Repérer les éventuels “features drift” (features binaires qui n’apparaissent qu’au tout début de la série temporelle par ex)

    df_train['feature'].hist()

  • Vérifier, par feature, les class imbalance et comprendre les biais que cela peut engendrer - https://developers.google.com/machine-learning/crash-course/overfitting/imbalanced-datasets?hl=fr

    df['target'].value_counts(normalize=True)

    Dans ces cas là, faire attention aux métriques utilisées, principalement pour les problèmes de classification

Session 3
To-Do

Faire du feature engineering

  • PCA - https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html
    • attention à bien standardiser les features si vous voulez faire du PCA !!
  • Supprimer les features “inutiles” en comparant les résultats des modèles avec et sans les features concernées
  • Ajouter de nouvelles features
    • ex : remplacer la quantité de pluie qui tombe par jour par “journée avec pluie vs sans pluie”
  • Rajouter les features scrappées de la fois précédente en faisant un merge avec le dataset

Utilisez skrub !! https://skrub-data.org/stable/

Encodage des features

  • Standard Scaling - pour les variables numériques
  • Ordinal Encoding
  • One-Hot Encoding
  • Target Encoding (attention au data leakage)

Faire le train/test split et le chargement des data

  • Mettre à jour le fichier data.py
    • au besoin, créer également un fichier features.py pour faciliter la transformation de votre dataset
    • attention, toutes les transformations que vous faites pour le train dataset doivent aussi être faites pour le test dataset !!

Finaliser l’EDA

  • Finir d’identifier les outliers et les données manquantes
  • Utiliser les librairies seaborn/plotly/matplotlib pour visualiser vos données
